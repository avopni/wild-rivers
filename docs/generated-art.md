# Generated game art

These project assets were made with the built-in imagegen tool. The Camp illustrations are in `public/camp/`; the replacement Alpaca is `public/alpaca.png`.

## Camp card prompt set

Each Camp image used this shared prompt, with the subject below substituted for `{subject}`:

> Use case: illustration-story. Asset type: square illustration for a tabletop game's Camp card. Subject: {subject}. Style: cute hand-painted storybook watercolor with crisp readable silhouette, gentle paper texture, warm cream background, coherent with whimsical woodland animal villagers. Composition: centered single object, generous margin, square card art. No text, no letters, no border, no watermark.

| Asset | Subject |
| --- | --- |
| `trail-pennant.png` | A small embroidered teal and coral banner planted beside a winding river, surrounded by soft reeds and a few pearl-like river stones. |
| `glowstone-lamp.png` | A glowing brass lantern hanging from a bent willow branch beside a small stream; amber light catching tiny floating fairy motes. |
| `wonder-basket.png` | A cozy woven picnic basket filled with bread, berries, and a folded teal cloth beside a woodland path. |
| `pearl-net.png` | A hand-tied fishing net draped over a curved wooden pole beside turquoise river water, with one luminous pearl caught in the mesh. |
| `whisperstrings.png` | A small traditional three-string lute resting on a woven mat under flowering branches, a few subtle musical notes as decorative shapes. |

## Alpaca prompt

> Use case: illustration-story. Asset type: transparent-background UI illustration for a tabletop game's Alpaca pearl holder. Primary request: one cute, anatomically recognizable fluffy alpaca in side profile facing left, standing calmly, with a broad unobstructed oval torso where six pearl slots will be overlaid in code. Style: charming clean storybook watercolor matching hand-painted woodland game cards, cream-colored wool, soft brown linework, friendly face, proportionate head and legs. Composition: full body horizontal, torso occupies the right two thirds, generous transparent margin, no objects behind animal. Constraints: genuinely transparent background, no text, no pearls, no slots, no harness, no props, no frame, no watermark.
