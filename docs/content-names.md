# Woodland magic names

The `prototype-2026.1` content release gives faeries elemental names and Camp cards magical tool and supply names. Powers, quantities, draw order, scoring and seeded outcomes are unchanged.

| Faerie | Power |
| --- | --- |
| Emberglow | Substitutes for one Camp card in a payment or matching pair. |
| Zephyr | Moves up to three pearls into compatible Villager sockets. |
| Moonveil | Waives the Camp cost of one placement. |
| Wildbloom | Makes one Villager socket permanently wild. |
| Dewdrop | Adds one pearl to a river collection. |

| Camp card | Matching-pair power | Artwork |
| --- | --- | --- |
| Trail Pennant | Advances an unplaced token in the turn order. | `public/camp/trail-pennant.png` |
| Glowstone Lamp | Takes a faerie from a board site. | `public/camp/glowstone-lamp.png` |
| Wonder Basket | Moves an owned token to an empty board space. | `public/camp/wonder-basket.png` |
| Pearl Net | Adds one pearl to a river collection. | `public/camp/pearl-net.png` |
| Whisperstrings | Moves the recruiting token to a later empty Village space. | `public/camp/whisperstrings.png` |

Retired names are removed from the application, action identifiers, assets, guides and editable mockup sources. IndexedDB saves and imported JSON from `prototype-2025.4` upgrade automatically, including every replay/undo snapshot, action log, coach explanation and pending setup checkpoint. Player-chosen names are preserved. Other rules versions keep their existing compatibility boundary.

The illustrations contain no printed card names. Their filenames change with the labels. The elemental names also appear in faerie acknowledgements, board sites, owned tokens, choices and accessibility text.
